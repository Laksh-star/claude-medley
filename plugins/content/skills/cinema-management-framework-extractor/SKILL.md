# Cinema Management Framework Extractor

Systematically extract management lessons and strategic frameworks from films using the methodology from "Directing Business: Movies and Management Lessons for Dreamers."

## Workflow Overview

1. **Selection Phase** - Choose analysis type and output format
2. **Analysis Phase** - Apply systematic analytical lenses
3. **Framework Extraction** - Identify actionable insights
4. **Output Generation** - Create content in selected format

## Step 1: Selection Phase

Begin by confirming the analysis parameters with the user:

### Analysis Type Selection

Present these options:

**A. Single Film Analysis**
- Deep dive into one film
- Extract multiple management lessons
- Best for: Detailed case studies, workshop materials

**B. Comparative Analysis**
- Analyze 2-3 films side by side
- Identify patterns and contrasts
- Best for: Thematic exploration, trend analysis

**C. Thematic Pattern Extraction**
- Focus on specific management concept across multiple films
- Examples: Leadership in crisis, Innovation patterns, Cultural transformation
- Best for: Framework development, research articles

### Output Format Selection

Present these options:

**1. Medium Article**
- Long-form thought leadership
- Uses a classic story-arc structure (McKee/Truby)
- Includes cultural bridges and technical credibility

**2. Workshop Case Study**
- Interactive format with discussion questions
- Specific scene analysis with timestamps
- Actionable takeaways for participants

**3. Movisvami Short-Form** (the short-form format used on Movisvami)
- Concise insight extraction (500-800 words)
- Social media friendly format
- Clear life/business lesson articulation

**4. Framework Document**
- Structured management framework
- Diagram-friendly format
- Implementation guidelines included

**Format**: "I'll analyze [Film Title] using [Analysis Type] and create a [Output Format]. Shall I proceed?"

Once confirmed, move to analysis.

## Step 2: Analysis Phase

Apply systematic analytical lenses. Load `references/analytical-lenses.md` for detailed frameworks.

### Core Analytical Process

For each film, examine:

**1. Leadership Dynamics**
- Character decision-making patterns
- Leadership styles (transformational, transactional, servant, authoritarian)
- Power dynamics and influence patterns
- Crisis management approaches

**2. Strategic Frameworks**
- Goal-setting and vision articulation
- Resource allocation decisions
- Risk assessment and mitigation
- Competitive positioning

**3. Organizational Patterns**
- Team dynamics and collaboration
- Hierarchy and reporting structures
- Communication flows
- Culture and values manifestation

**4. Change & Innovation**
- Resistance to change patterns
- Innovation adoption curves
- Transformation management
- Disruption responses

**5. Conflict Resolution**
- Negotiation strategies
- Stakeholder management
- Ethical dilemmas
- Win-win vs win-lose approaches

**6. Cultural Context**
- Regional/cultural business norms (especially for Telugu cinema)
- Classical literature parallels (Sanskrit texts, Annamayya keerthanas)
- Universal vs context-specific lessons
- Cross-cultural applicability

**7. Directorial Signals**
- Visual metaphors for business concepts
- Cinematography choices that reveal management principles
- Narrative structure parallels to business journeys
- Symbolic representations

### Evidence Collection

For each insight identified:
- **Scene identification**: Specific timestamp or scene description
- **Character actions**: What actually happened
- **Management principle**: What it illustrates
- **Business parallel**: Real-world application
- **Cultural depth**: Classical/literary connections when relevant

## Step 3: Framework Extraction

Transform analysis into actionable frameworks:

### Framework Structure

Each extracted framework should include:

**Framework Name**: Clear, memorable title

**Core Principle**: One-sentence essence

**Components**: 3-5 key elements with explanations

**Film Evidence**: Specific scenes demonstrating each component

**Business Application**: How to implement in organizations

**Quality Indicators**: Metrics for successful application

**Cautionary Notes**: When framework doesn't apply

### Multi-Stakeholder Perspective

Apply a multi-stakeholder lens:
- Who benefits from this framework?
- Who might resist it?
- What incentives drive each stakeholder?
- What omissions or blind spots exist?
- What are second-order effects?

## Step 4: Output Generation

Load `references/output-templates.md` for format-specific structures.

### Quality Standards

Every output must include:

✓ **Specific scene citations** - No vague references
✓ **Multiple evidence points** - At least 3 examples per major insight
✓ **Actionable frameworks** - Clear implementation steps
✓ **Cultural depth** - Context and classical connections when relevant
✓ **Voice consistency** - Match the Directing Business analytical style

Load `references/book-examples.md` to see reference analyses and voice calibration.

### Output Format Guidelines

**Medium Article**: McKee/Truby narrative structure, cultural bridges, technical credibility

**Workshop Case Study**: Include facilitation notes, discussion questions, timing guidance

**Movisvami Content**: Focus on life lessons over pure business, accessible language, emotional resonance

**Framework Document**: Diagram-ready structure, implementation checklist, measurement criteria
